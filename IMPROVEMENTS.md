## version `0.1.0` to `0.2.0`

### 💾 Data Persistence

- [x] **Local Storage Sync**: Automatically save form progress to `localStorage` to prevent data loss on refresh.
- [X] **Persistence Indicators**: Add "Saved" / "Syncing" status indicators in the header.

### 🔬 Form2Research Enhancements

- [x] **Live LaTeX Helper**: Real-time preview for the equation editor.
- [x] **Internal Referencing**: Support for citing figures and tables within the manuscript text (e.g., "[Fig. 1]").

- [x] **User Onboarding**: Create a guided tour for new users (e.g., using `driver.js` or `react-joyride`) to explain how the builders work.
- [x] **Performance**: Optimize KaTeX loading and form state management for smoother editing.
