# Form2X - Modern Modular Documentation

**Form2X** is a modular suite of hyper-structured document generators designed to convert simple forms into high-fidelity, industry-standard outputs with precision and speed.

## 🚀 Solutions

Form2X currently provides two specialized builders:

### 1. Form2Resume

* **Purpose**: Create professional, ATS-optimized resumes in minutes.
* **Target**: Engineered for engineers and professionals.
* **Key Features**:
  * Clean, minimalist design.
  * ATS-friendly formatting to pass through recruiter screening.
  * Hyper-structured data entry for consistent results.

### 2. Form2Research

* **Purpose**: Generate IEEE standard research papers.
* **Key Features**:
  * Full support for **LaTeX equations**.
  * Automatic citation management.
  * Figure and table integration.
  * Industry-standard paper formatting.

## ✨ Features

### 🎓 User Onboarding

* **Guided Tour**: First-time visitors are greeted with an interactive tour powered by [driver.js](https://driverjs.com/)
* **Smart Persistence**: The tour automatically remembers completion status using localStorage
* **Beautiful Design**: Custom-styled tour popovers that match Form2X's design system with full light/dark mode support
* **Manual Trigger**: Users can restart the tour anytime via the help button

### 💾 Data Persistence

* **Auto-Save**: All form progress is automatically saved to localStorage
* **No Data Loss**: Your work is preserved even if you accidentally close the browser
* **Status Indicators**: Visual "Saved" / "Syncing" feedback in the header

### 🎨 Premium UI/UX

* **Dark Mode**: Seamless theme switching with system preference detection
* **Responsive Design**: Optimized for all screen sizes
* **Smooth Animations**: Micro-interactions and transitions for enhanced user experience
* **Modern Aesthetics**: Glassmorphism effects, vibrant gradients, and premium styling

## 🛠 Tech Stack

* **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
* **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Equations**: [KaTeX](https://katex.org/) (LaTeX Engine)
* **UI Components**: Radix UI & Shadcn/UI
